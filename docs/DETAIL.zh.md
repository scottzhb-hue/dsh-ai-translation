**AI辅助翻译**把完整的 CAT（计算机辅助翻译）工作台搬进 DeepSeek Harness：左边原文、右边译文，翻译记忆与术语库随句段实时命中，AI 生成译文建议，排版仍按原文档结构保留。

### 主要能力

- **多种格式**：DOCX / XLSX / PPTX / EPUB / TXT / Markdown / SDLXLIFF / TMX / CSV 导入导出，译文写回原文档版式；旧版 `.doc / .xls / .ppt` 也能在本机安装 Office 的情况下直接导入。
- **翻译记忆与术语库**：自动匹配、批量预翻译、术语提示，记忆库与术语库可建多个、按项目挂载，支持 TBX / CSV / JSON / TMX 导入导出。
- **AI 参与翻译**：单句「生成译文建议」、整篇预翻译、工作台内常驻 AI 助手，可用对话把要求整理成项目说明。
- **审校与质检**：确认/待审状态、重点审标记、一致性检查与审校报告。

### 相对上游 CAIT 的本地增强

- 句段可合并、可拆分：识别 `Aug.`、`St.` 等人名缩写不再误断句，DOCX 拆分后两半仍写回同一段落（用换行分隔）。
- 选中原文与译文即可定义术语，按住 Shift 可跨段落强制合并。
- 未确认的译文自动暂存，重开项目自动恢复，不会因为误操作丢失。
- AI 助手支持多轮对话、把对话整理成项目说明，并对消息结构做防御校验。
- 模型路由自动跳过识图包装路由，失败时显示真实原因，而不是笼统的「操作失败」。
- 内置 Token 用量与费用统计（按官方价、区分峰谷），随时看清成本。

### 数据与隐私

项目数据全部存放在本机 `~/.dsh/cait`（文档、翻译记忆、术语库、草稿快照）；除你选择的 DSH 模型路由外，不会有任何网络外发请求。
