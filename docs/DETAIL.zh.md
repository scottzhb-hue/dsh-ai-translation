**AI辅助翻译**把完整的 CAT（计算机辅助翻译）工作台搬进 DeepSeek Harness：左边原文、右边译文，翻译记忆与术语库随句段实时命中，AI 生成译文建议，排版仍按原文档结构保留。

它不是把网页翻译搬进来，而是把译员真正会用到的那套流程补齐：**导入 → 翻译 → 审校 → 交付 → 报价 → 结算**，并且一批文件可以挂在同一个项目下共享说明与术语库。

### 主要能力

- **多种格式**：DOCX / XLSX / PPTX / EPUB / TXT / Markdown / SDLXLIFF / TMX / CSV 导入导出，译文写回原文档版式；旧版 `.doc / .xls / .ppt` 也能在本机安装 Office 的情况下直接导入（导入前强制关闭宏）。
- **翻译记忆与术语库**：自动匹配、批量预翻译、术语提示；记忆库与术语库可建多个、按项目挂载，支持 TBX / CSV / JSON / TMX 导入导出。
- **AI 参与翻译**：单句「生成译文建议」、整篇预翻译、工作台内常驻 AI 助手，可用对话把要求整理成项目说明。
- **审校与质检**：确认/待审状态、重点审标记、一致性检查与审校报告。

### 相对上游 CAIT（1.1.8）的重大更新

**1. 项目层：一批文件当一个活干**

这是本分支最大的一块新增。一个客户、一批文件、一份项目说明（brief）、一套术语库，现在是真实的数据结构，而不是十几个互不相干的标签页：

- 打开插件先进入**项目视图**：左列项目，右侧项目详情（文档清单、四档状态与进度、句段/字数/工时/报价、匹配分析）。
- **共享 brief 与共享 TM/术语库**：项目填一次，项目内每篇文档自动继承；文档自己的设置优先，也可以选择不读某个库。
- **项目级分析、报价、报告、交付包**：一次算完整个项目，按同一批数字出报价，HTML（可打印）与 CSV 两种报告，一键打包目标稿、双语稿、术语表、质检与分析 CSV、批注与交付说明。
- **未分类与所有文档**：没有归属的文档自动进「未分类」；另有跨项目的「所有文档」总表，按「未翻译 / 未完成 / 已译待确认 / 已完成」筛选。
- **工时**：项目级秒表（重启后继续计时）加手动补记，可按客户统计投入。
- **文档顺序**：项目内文档可上移、下移，顺序随项目保存，未分类同样可排序。

**2. 交付与商务**

- **交付前检查**：空译、未确认、源文照抄、未关批注、QA 高危，一屏看清再打包。
- **批量动作**：按待译 / 未确认 / 高风险 / 重复 / 新句段 / 模糊 / 锁定 / 批注筛选后批量确认、锁定、解锁、清空。
- **报价单**：按匹配档位折扣（ICE / 100% / 85–99% / 70–84% / 新句段）计价，可导出 TXT / CSV / JSON。
- **译后编辑度量**：确认句段时记录 MT 建议的保留率，按客户看返工水平。
- **本地 MT**：可指向 LM Studio / Ollama / vLLM 等本机 OpenAI 兼容端点，敏感文本不出本机。

**3. 翻译内核**

- **句段合并放开**：同段落合并对所有格式开放，按住 Shift 可跨段落强制合并；中文混排不再硬插空格；`Aug.` / `St.` 这类缩写不再被误切成两句。
- **DOCX 同段拆分**：拆开的两半写回同一个段落（换行分隔），导出后版式不散。
- **选中即建术语**：选中原文与译文，右键或 `Ctrl+Alt+T` 即写入默认术语库，首次使用有提示。
- **未确认译文自动暂存**：草稿写到 `drafts/`，崩溃或误关后自动恢复。

**4. AI 与成本**

- **AI 对话框**：新建文档后的 brief 引导、预翻译前的指令确认、编辑器顶部常驻指令条；多轮对话可一键整理成项目说明。
- **路由避坑**：自动跳过识图包装路由，失败时显示真实原因而不是笼统的「操作失败」。
- **Token 用量与费用**：按官方价、区分峰谷，按文档/模型/日期汇总，译前能估、译后能对账。

**5. 界面与可靠性**

- **欢迎页**：粘贴文本 / 导入文件（支持多选、多拖、进度可取消）、接着上次、继续工作列表。
- **顶栏按场景分组**：新建/导入只出现在项目页，编辑器只留 用量 · 预翻译 · 查找替换 · 交付 · 更多。
- **可见的失败**：渲染异常有错误边界（可复制错误信息 + 重试），库加载有超时与重试，不再整窗白屏或无限转圈。
- **三语一致**：中文 / English / 日本語 共 930 个文案键逐条对齐；127 个错误码都有可读提示。

### 数据与隐私

项目数据全部存放在本机 `~/.dsh/cait`（文档、翻译记忆、术语库、草稿快照）；除你选择的 DSH 模型路由外，不会有任何网络外发请求。
