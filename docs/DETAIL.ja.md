**AI翻訳**は、本格的な CAT（翻訳支援）ワークベンチを DeepSeek Harness に組み込みます。左に原文、右に訳文、セグメントを移動すると翻訳メモリと用語集がヒットし、AI が訳文候補を提示、書き出しは元のレイアウトを保ちます。

単なる「Web 翻訳のパネル」ではありません。実際の翻訳者が通る流れ——**取り込み → 翻訳 → レビュー → 納品 → 見積 → 精算**——を一通りそろえ、複数ファイルを 1 つのプロジェクトにまとめて共通ブリーフと用語集を共有できます。

### 主な機能

- **多彩な形式**：DOCX / XLSX / PPTX / EPUB / TXT / Markdown / SDLXLIFF / TMX / CSV の入出力に対応し、訳文は元のレイアウトに書き戻されます。Microsoft Office がインストールされていれば旧形式の `.doc / .xls / .ppt` も取り込めます（変換前にマクロを強制無効化）。
- **翻訳メモリと用語集**：自動マッチ、一括プリトランスレート、用語ヒント。プロジェクトごとに複数のメモリと用語集を紐付け、TBX / CSV / JSON / TMX の入出力が可能です。
- **AI の活用**：セグメント単位の訳文候補、文書全体のプリトランスレート、ワークベンチ内の AI アシスタント（会話をプロジェクト説明に整理できます）。
- **レビューと品質管理**：確定／未確定の状態管理、重点レビュー印、整合性チェックとレビュー報告。

### 上流 CAIT 1.1.8 からの主なアップデート

**1. プロジェクト層——顧客 1 件・ファイル群 1 式を 1 つの案件として**

本フォーク最大の追加です。顧客、ファイル群、ブリーフ、用語集が、無関係なタブの集まりではなく実体あるデータ構造になりました。

- プラグインを開くと**プロジェクト一覧**。右側はプロジェクト詳細（ドキュメント表、4 段階の状態と進捗、セグメント／語数／作業時間／見積、マッチ分析）。
- **ブリーフと TM／用語集の共有**：プロジェクトで 1 回設定すれば各ドキュメントが継承。ドキュメント側で上書きも、ライブラリを読まない選択も可能。
- **プロジェクト単位の分析・見積・レポート・納品**：バッチ全体を 1 回で分析し、同じ数値から見積を作成。印刷可能な HTML レポートと CSV、訳文・対訳・用語集・品質チェック・分析 CSV・コメント・納品書を 1 つの ZIP にまとめます。
- **未分類と「すべてのドキュメント」**：所属のない文書は「未分類」へ。横断的な一覧を「未翻訳／未完了／翻訳済み・未確認／完了」で絞り込めます。
- **作業時間**：プロジェクト単位のストップウォッチ（再起動後も継続）と手動記録、顧客別の集計。
- **ドキュメント順序**：プロジェクト内で上下に並べ替え、順序は保存されます（未分類も同様）。

**2. 納品とビジネス**

- **納品前チェック**：空訳、未確定、原文コピー、未クローズのコメント、高リスク QA を 1 画面で確認してから梱包。
- **一括操作**：未翻訳／未確定／高リスク／重複／新規／ファジー／ロック／コメントで絞り込み、まとめて確定・ロック・解除・クリア。
- **見積書**：マッチ帯（ICE / 100% / 85–99% / 70–84% / 新規）ごとの割引で計算し、TXT / CSV / JSON に出力。
- **ポストエディット指標**：確定時に MT 候補の保持率を記録し、顧客ごとの手戻りを可視化。
- **ローカル MT**：LM Studio / Ollama / vLLM など手元の OpenAI 互換エンドポイントを指定でき、機密文書を外部に出さずに翻訳できます。

**3. 翻訳の中核**

- **結合の解放**：同一段落の結合を全形式で許可、Shift で段落をまたぐ強制結合。CJK とラテン文字の連結で余計な空白が入らず、`Aug.` や `St.` などの略語で文が切れません。
- **DOCX の同段落分割**：分割した 2 つは同じ段落に書き戻され（改行区切り）、書き出し後もレイアウトが崩れません。
- **選択して用語登録**：原文と訳文を選択して右クリックまたは `Ctrl+Alt+T` で既定の用語集へ登録（初回はヒント表示）。
- **下書きの自動退避**：未確定の訳文は `drafts/` に保存され、クラッシュや誤操作の後でも復元されます。

**4. AI とコスト**

- **AI ダイアログ**：文書作成直後のブリーフ案内、プリトランスレート前の指示確認、エディタ上部の常設コマンドバー。複数ターンの会話をプロジェクト説明に整理できます。
- **経路の堅牢化**：視覚ラッパー経路を自動的に回避し、失敗時は「操作失敗」ではなく実際の原因を表示します。
- **トークン使用量と費用**：公式価格・ピーク／オフピーク対応で、文書／モデル／日付ごとに集計。翻訳前の見積と翻訳後の照合ができます。

**5. 画面と信頼性**

- **ホーム画面**：テキスト貼り付け／ファイル取り込み（複数選択・複数ドロップ・キャンセル可能な進捗）、前回の続き、作業中一覧。
- **状況に応じたツールバー**：新規／取り込みはプロジェクト画面のみ。エディタは 使用量 · プリトランスレート · 検索置換 · 納品 · その他 に整理。
- **見える失敗**：描画エラーはエラーバウンダリで表示（コピー可能なメッセージ＋再試行）、ライブラリ読み込みにはタイムアウトと再試行。真っ白や無限スピナーになりません。
- **3 言語の一致**：中国語／英語／日本語で 930 個の UI キーを揃え、127 個のエラーコードすべてに読めるメッセージを用意。

### データとプライバシー

プロジェクトのデータはすべて本機の `~/.dsh/cait` に保存されます（文書、翻訳メモリ、用語集、下書きスナップショット）。選択した DSH のモデル経路以外に外部送信はありません。
