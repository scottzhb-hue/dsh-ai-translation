**AI翻訳**は、本格的な CAT（翻訳支援）ワークベンチを DeepSeek Harness に組み込みます。左に原文、右に訳文、セグメントを移動すると翻訳メモリと用語集がヒットし、AI が訳文候補を提示、書き出しは元のレイアウトを保ちます。

### 主な機能

- **多彩な形式**：DOCX / XLSX / PPTX / EPUB / TXT / Markdown / SDLXLIFF / TMX / CSV の入出力に対応し、訳文は元のレイアウトに書き戻されます。Microsoft Office がインストールされていれば旧形式の `.doc / .xls / .ppt` も取り込めます。
- **翻訳メモリと用語集**：自動マッチ、一括プリトランスレート、用語ヒント。プロジェクトごとに複数のメモリと用語集を紐付け、TBX / CSV / JSON / TMX の入出力が可能です。
- **AI の活用**：セグメント単位の訳文候補、文書全体のプリトランスレート、ワークベンチ内の AI アシスタント（会話をプロジェクト説明に整理できます）。
- **レビューと品質管理**：確定／未確定の状態管理、重点レビュー印、整合性チェックとレビュー報告。

### 上流 CAIT に対するローカル拡張

- セグメントの結合と分割：`Aug.` や `St.` などの人名略語で文が分割されず、DOCX を分割しても同一段落に書き戻されます（書き出し時は改行区切り）。
- 原文と訳文を選択するだけで用語を登録でき、Shift 併用で段落をまたいだ強制結合もできます。
- 未確定の訳文は自動的に退避され、プロジェクトを開き直すと復元されます。
- AI アシスタントは複数ターンの履歴を保持し、会話をプロジェクト説明に整理でき、メッセージ構造を防御的に検証します。
- モデル経路は視覚ラッパーを自動的に回避し、失敗時は「操作失敗」ではなく実際の原因を表示します。
- トークン使用量と概算費用の集計を内蔵（公式価格、ピーク／オフピーク対応）。
- 複数ドキュメントを 1 つの**プロジェクト**にまとめ、共通ブリーフと記憶／用語集を共有し、プロジェクト単位でマッチ分析・見積・レポート・納品パッケージ・作業時間の集計ができます。未所属のドキュメントは「未分類」に入り、横断的な「すべてのドキュメント」一覧もあります。

### データとプライバシー

プロジェクトのデータはすべて本機の `~/.dsh/cait` に保存されます（文書、翻訳メモリ、用語集、下書きスナップショット）。選択した DSH のモデル経路以外に外部送信はありません。
